# 🧠 Neural Networks Visualizer

An interactive, web-based platform built to demystify deep learning concepts through real-time feedforward propagation, backpropagation, and 2D/3D network architecture visualizations.

---

## ✨ Key Features

* ⚙️ **Dynamic Network Architectures:** Configure layers, neurons, learning rates, batch sizes, and activation functions (*ReLU, Sigmoid, Tanh, Softmax*) on the fly.
* 🔄 **Live Propagation & Backpropagation:** Track forward pass activation states, gradient propagation, and real-time weight updates.
* 🌐 **2D & 3D Interactive Topologies:** Render neural layers and connection weights in dynamic 2D graph views and immersive 3D scene renderings.
* 📐 **Math & Analytical Insights:** Display live mathematical formulations, loss curves, confusion matrices, and prediction probabilities.
* 📊 **Custom Dataset Ingestion:** Load custom CSV datasets, adjust training execution speeds, and observe live decision boundaries.

---

## 🛠️ Tech Stack

* **Frontend:** React, TypeScript, HTML5, CSS3/Tailwind
* **Visualization:** Modern WebGL / Canvas / Three.js charting engines
* **Backend Runtime:** Node.js, Express.js
